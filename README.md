# Pi 架构图解

对开源项目 [earendil-works/pi](https://github.com/earendil-works/pi) 的架构分析站点：结构化中英双语文字、手工设计的 SVG 架构图、20 页网页幻灯片。

- 线上地址：https://pi-analysis.pages.dev/
- 幻灯片：https://pi-analysis.pages.dev/slides.html
- 静态站点文件在 `site/`，直接打开 `site/index.html` 即可离线浏览。

## 版本
