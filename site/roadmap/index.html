02Roadmap

包模板Package template#

每个包页面按以下 9 项组织；完成的包页面全部覆盖，占位页显示进度。Every package page is organised by these nine parts; finished pages cover all of them, placeholders show progress.

  • 概览Overview定位、依赖、规模、一句话结论role, deps, size, one-line takeaway
  • 公共 APIPublic API导出路径与导出符号（逐行链接）export paths and exported symbols (line-linked)
  • 内部架构图Internal architecture模块 / 文件之间的结构structure between modules and files
  • 关键流程Key flows时序、状态机、数据流sequences, state machines, data flow
  • 数据类型Data types核心接口与它们的关系core interfaces and how they relate
  • 扩展点Extension points宿主可以替换或注入的地方where a host can plug in or replace behaviour
  • 关键文件Key files链接到 v1.1.0 的具体行links to exact lines at v1.1.0
  • 测试Tests测试文件与用例数test files and case counts
  • 交叉链接Cross-links相关包与相关章节related packages and sections
